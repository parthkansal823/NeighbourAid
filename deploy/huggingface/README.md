# NeighbourAid API

Backend for [NeighbourAid](https://github.com/parthkansal823/NeighbourAid), a
hyperlocal crisis-response network for India. This Space runs the FastAPI
service only — the React frontend is deployed separately on Cloudflare Pages.

This README is the Space's configuration file: the frontmatter above tells
Hugging Face to build the Dockerfile and route traffic to port 7860. It is
generated by `deploy/huggingface/push-space.sh` in the main repo — edit it
there, not here, or the next push overwrites your changes.

## Endpoints

| Path | Purpose |
|---|---|
| `/docs` | Interactive OpenAPI documentation |
| `/health` | Liveness — checks nothing, never fails while the process is up |
| `/health/ready` | Readiness — pings MongoDB, reports the live triage engine |
| `/api/...` | Application API |
| `/ws/volunteer` | WebSocket feed for volunteers |

## Required secrets

Set these in **Settings → Variables and secrets**. The Space will build
without them but will not work correctly:

| Secret | Required | Notes |
|---|---|---|
| `MONGO_URL` | Yes | MongoDB Atlas connection string |
| `JWT_SECRET` | Yes | ≥32 random bytes. The app refuses to start in production on the built-in dev default |
| `ENVIRONMENT` | Yes | Set to `production` |
| `ANTHROPIC_API_KEY` | No | Without it, triage falls back to a keyword heuristic and still works |
| `FRONTEND_ORIGINS` | No | Only for a custom frontend domain; `*.pages.dev` is already allowed |

## Keeping it warm

Free Spaces sleep after 48 hours of inactivity. An uptime monitor polling
`/health/ready` every 5 minutes keeps the Space awake, the Mongo connection
pool open, and the Anthropic client constructed — none of which costs an API
call. See `DEPLOY.md` in the main repo.
