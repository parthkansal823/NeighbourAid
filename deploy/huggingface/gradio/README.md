# NeighbourAid API

Backend for [NeighbourAid](https://github.com/parthkansal823/NeighbourAid), a
hyperlocal crisis-response network for India. This Space runs the FastAPI
service; the React frontend deploys separately to Cloudflare.

Runs on the **Gradio** SDK rather than Docker, because Docker Spaces are a
paid feature on some accounts while Gradio is free. `app.py` mounts a small
Gradio landing page at `/ui` and serves the real API everywhere else.

This README is the Space's config file — the frontmatter above is what tells
Hugging Face how to run it. It is generated by
`deploy/huggingface/push-gradio-space.sh` in the main repo; edit it there, or
the next push overwrites your changes.

## Required secrets

**Settings → Variables and secrets.** The Space builds without them but will
not work:

| Secret | Required | Notes |
|---|---|---|
| `MONGO_URL` | Yes | MongoDB Atlas connection string |
| `JWT_SECRET` | Yes | ≥32 random bytes; the app refuses to start in production on the built-in dev default |
| `ENVIRONMENT` | Yes | Set to `production` |
| `ANTHROPIC_API_KEY` | No | Leave unset to run entirely free — triage falls back to the multilingual keyword heuristic |
| `FRONTEND_ORIGINS` | No | Only for a custom frontend domain |

## Triage without an API key

With no `ANTHROPIC_API_KEY`, urgency classification runs on the keyword
heuristic in `app/services/vocab.py`. It covers all eight languages the app
ships in — English, Hindi (both scripts), Bengali, Tamil, Telugu, Marathi,
Gujarati and Punjabi — costs nothing, needs no network, and answers in under
a millisecond. Less accurate than Claude on unusual phrasing, but it is a
real classifier, not a stub.

Check which engine is live at `/health/ready`.

## Keeping it warm

Free Spaces sleep after 48 hours of inactivity. An uptime monitor polling
`/health/ready` every 5 minutes keeps the Space awake and the Mongo
connection pool open at no cost.
