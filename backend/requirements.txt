# Web push (app/services/push.py). These two, not `pywebpush`: pywebpush is
# the reference implementation but hard-depends on BOTH aiohttp and requests
# — thirteen packages and two more HTTP clients, in a project that already
# ships httpx. These are the libraries pywebpush itself uses for the parts
