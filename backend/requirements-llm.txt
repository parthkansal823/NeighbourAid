# Optional: local GGUF text models (Gemma first-pass and an optional stronger
# verifier). NOT installed by requirements.txt or the default Docker target.
#
# Triage works with no model at all — app/services/vocab.py scores 95% on the
# eval set at ~0.1 ms per report using no weights, no network and no API key.
# Urgency assistance runs only where the classifier matched nothing. The
# optional safety-review models run after an alert is saved; all model failures
# retain the deterministic path. See app/services/llm.py and enrich.py.
#
# Keeping it out of requirements.txt keeps the backend image small and its
# build free of a compiler: the wheel below is prebuilt, but llama-cpp-python
# still pulls in a native runtime that the keyword path never needs.
#
# Install (the wheel is NOT on PyPI — it needs the project's own index):
#
#   pip install -r requirements-llm.txt \
#     --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
#
# Then point LLM_MODEL_PATH (and, if desired, LLM_VERIFIER_MODEL_PATH) at
# local GGUF files — see models/README.md for the supported deployment setup.
llama-cpp-python>=0.3.35
